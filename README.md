# Space Rocket - Jogo de Multiplicador

## Descrição
Este projeto é uma variação temática do jogo Aviator, onde um foguete espacial substitui o avião tradicional. O jogador aposta e tenta retirar seus ganhos antes que o foguete exploda ao atingir seu limite. O jogo foi desenvolvido com HTML, CSS (Tailwind) e JavaScript puro.

### Mecânica do Jogo
- **Multiplicador crescente**: O valor multiplicador aumenta progressivamente
- **Retirada antecipada**: O jogador pode retirar os ganhos a qualquer momento
- **Fim automático**: O jogo termina quando atinge um multiplicador aleatório pré-definido
- **Contagem regressiva**: Início automático após 7 segundos do término

### Ambiente Espacial
- **Foguete animado**: Subindo verticalmente com trajetória suave
- **Cenário dinâmico**: Estrelas cintilantes e asteroides em movimento
- **Efeitos visuais**: Explosão quando o foguete atinge o limite

### Sistema de Apostas
- **Saldo do jogador**: Exibido no cabeçalho
- **Controles flexíveis**: Botões +/- e valores rápidos de aposta
- **Histórico completo**: Registro das últimas 20 jogadas

## Como Jogar

1. Insira o valor da aposta usando os botões +/- ou valores rápidos
2. Clique em "Apostar" para lançar o foguete
3. Observe o multiplicador crescer enquanto o foguete sobe
4. Clique em "Retirar" para garantir seus ganhos
5. O foguete explode automaticamente se atingir seu limite
6. Novo lançamento inicia automaticamente após 7 segundos

## Personalização

Você pode ajustar:
- Valores mínimos/máximos de aposta
- Velocidade de ascensão do foguete
- Quantidade e tamanho de estrelas/asteroides
- Cores e estilos visuais
